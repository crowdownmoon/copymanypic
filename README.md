# Screenshot Tool Chrome Extension

一个功能强大的 Chrome 截图扩展。

## 功能特点

- 🎯 便捷的悬浮球操作界面
- 📸 自由选择截图区域
- 💾 支持快速保存和缓存截图
- 📁 智能记忆保存路径
- 📋 支持批量复制图片到剪贴板
- 🖼️ 简洁的截图管理界面
- ⌨️ 支持快捷键操作

## 安装方法

1. 下载源代码
2. 打开 Chrome 浏览器，进入扩展程序页面 (chrome://extensions/)
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目目录

## 使用说明

1. 点击右下角的"截图"悬浮球开始截图
2. 在页面上拖动选择要截图的区域
3. 选择完成后可以：
   - 点击"保存"按钮保存到本地
   - 点击"缓存"按钮保存到扩展缓存
4. 点击"管理"悬浮球查看所有缓存的截图
5. 在管理界面可以：
   - 选择多张图片（最多20张）
   - 复制选中的图片到剪贴板
   - 清空所有缓存的截图

## 快捷键

- `Esc`: 退出截图模式

## 开发技术

- Chrome Extension APIs
